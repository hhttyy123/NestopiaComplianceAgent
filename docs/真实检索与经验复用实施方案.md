# 真实检索与经验复用实施方案

## 目标与主干

输入项目事实 → AI生成调查问题与检索词 → 官方站点搜索 → 获取原文并保存版本 → AI阅读相关段落并输出建议 → 校验引用 → 保存调查与反馈 → 后续调查参考经验、按时效复用资料。

不以手写地区法规规则决定合规；程序规则只管理输入、来源安全、缓存、结构与引用真实性。缺少原文时不得用预设答案补齐。

## 已完成的实现

1. 用户自由填写产品、位置、建设方式、尺寸及疑问；未知事实不自动补造。
2. DeepSeek Flash提出2至5条检索词、辖区判断、待确认信息和议题。
3. 通过DeepSeek Search查询，过滤到允许的官方域名，再通过Fetch获取最多6份独立原文。查询结果缓存6小时，原文24小时；强制刷新绕过缓存。
4. 保存完整返回Markdown、段落、官方URL、时间与SHA-256版本。分析只选择相关段落，模型明确知道未读完全部法规；未保存原始PDF字节。
5. AI生成条件性建议、冲突或未知，以及缺失信息和行动清单。逐条检查引用ID和逐字引文，结构或引用错误最多修复两次，仍错误则失败。
6. 异步进度、历史报告、来源阅读、反馈与重启恢复均已接入。失败任务保留已获取的资料，不伪造结论。
7. 同产品、同位置的近期调查提供缺失项、行动项及反馈作为经验。纠错后的记录不再提供原行动项；所有经验均不得作为法律依据。不是模型训练，目前未做语义相似检索。
8. 旧固定引擎、提示词、样例和相关界面归档到archive/v1，不参与构建及生产路由。旧数据库保留，当前入口只读取新研究记录。空库不导入任何项目。

## 边界与后续扩展

当前来源策略覆盖.gov、.gov.uk、.gc.ca和Montgomery Planning官方域名，不保证全球覆盖；应根据实际目标地区添加可验证的官方来源。搜索、原文提取与分析同由DeepSeek提供，原文可回看但不是跨供应商独立证明。

本轮采用有上限的单轮资料调查与输出修复；证据仍不足会明确列缺口，需要补充条件后再次调查，不承诺无限递归补查。没有完整法律生效关系图、工程计算、语义经验检索或政府审批能力。引用逐字匹配不能证明适用性解释正确。
