## 案例与功能边界

[填写资料与原文链接](马里兰真实案例测试.md)提供3份真实申请，涉及2个地址，其中同址先后申请用于核对最终拒绝结果。不是虚构案例，不注入正式数据库。

当前可用：真实输入、实时检索、官方PDF/网页原文存档、带引文的AI评价、许可材料表、证据支持的阶段估算、追问、反馈、经验参考、材料保存、删除与恢复。

本版不内置演示项目、不使用固定答案或模型失败后的虚构替代结论。测试中的传输桩只用于自动检查，不参与用户请求；archive/v1和knowledge为历史研发存档，不进入发布包。

仍有明确边界：

1. 最新真实案件复核仍发现最终命令可能漏读，相关事项会标待核实；尚不能保证历史案件结果完全准确。AI复核也会判断错误，不能当自动签认或政府批准。PDF提取不保留删除线、下划线等修订版视觉语义，遇到新旧文本冲突必须结合现行法进一步确认，不能只据一段修订PDF断言。
2. 资料准备、补件和发证没有可比时长时，总周期仍不能完整估算；不能将已知首轮审查时间冒充总周期。已有数字也只作为带口径和前提的规划估算。
3. 无自动提交许可、政府审批状态同步、PE签章、多租户账号隔离；仅支持当前范围的小团队共享工作空间。
4. 现有示例测试覆盖软件行为，不证明所有地块法规覆盖完整，也不是3个不同地块的独立准确率测评。
5. 本机未运行Docker引擎，尚未实际构建Linux容器或验收公网DNS/TLS；未获得VPS连接信息，未执行公网部署。必须按[VPS步骤](VPS上线.md)完成服务器验收后再对外分发密码。
